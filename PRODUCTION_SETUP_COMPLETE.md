### 2. **Nginx Configuration** (Generated by setup script)

**Location:** `/etc/nginx/sites-available/backend-proxy`

**What it does:**
- Listens on port 80 (HTTP)
- Listens on port 443 (HTTPS with SSL)
- Redirects all HTTP to HTTPS
- Proxies requests to backend on localhost:8080
- Adds security headers
- Logs all traffic
- Handles WebSocket upgrades
- Manages connection pooling

**Key Features:**
```nginx
upstream backend {
    server 127.0.0.1:8080;
    keepalive 64;  # Connection pooling
}

server {
    listen 443 ssl http2;  # HTTPS with HTTP/2
    server_name dev-api.broandbro.in;
    
    ssl_certificate /etc/letsencrypt/live/dev-api.broandbro.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/dev-api.broandbro.in/privkey.pem;
    
    # Security headers
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    
    # Proxy configuration
    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_read_timeout 300s;
        proxy_connect_timeout 300s;
    }
}
```

### 3. **Backend CORS Configuration**

**File:** `backend/src/main/resources/application-dev.yml`

**Added:**
```yaml
app:
  cors:
    allowed-origins: "${APP_CORS_ALLOWED_ORIGINS:https://develop.broandbro.in,http://localhost:5173}"
```

**What it does:**
- ✅ Allows requests from `https://develop.broandbro.in` (prod frontend)
- ✅ Allows requests from `http://localhost:5173` (local dev)
- ✅ Rejects requests from other origins (security)

**How to update:**
```bash
# Add more origins
export APP_CORS_ALLOWED_ORIGINS="https://develop.broandbro.in,https://staging.broandbro.in"

# Or in systemd service
Environment=APP_CORS_ALLOWED_ORIGINS=...
```
